#### Simulations

**[Omran](https://github.com/ahmedaly0904-bit64/Omran)**

Ibn Khaldun's theory of *asabiyyah* as a simulation. Nations on a grid, RK4 for
population dynamics, an SIR model for how ideas spread, wars along shared
borders. The engine is written from scratch in Python and NumPy.

**[Rasad-Sim](https://github.com/ahmedaly0904-bit64/Rasad-Sim)**

Built because Omran's results changed with the random seed, and there was no way
to tell how much of a result was the model and how much was the seed. Rasad
measures that split for any stochastic simulation, without modifying it.

**[Physics-Sim](https://github.com/ahmedaly0904-bit64/Physics-Sim)**

Small physics and numerical analysis notebooks: projectile motion, random walks,
the logistic map, numerical integration, root finding. Each one has a README
explaining the mathematics behind it.
